# Projeto D’Rute Modelista

## Status

Proposta exploratória V1.

O conteúdo atual foi criado a partir de uma conversa inicial, antes do discovery completo com a cliente. Ele serve para contextualizá-la sobre possibilidades e testar se a direção conversa com seus gostos. Informações ainda não confirmadas devem ser tratadas como hipóteses.

## Cliente

D’Rute.

Modelista e piloteira com mais de 30 anos de experiência no setor de vestuário.

Sua trajetória profissional inclui experiência desde a linha de produção até atividades de desenvolvimento, modelagem e pilotagem.

Atualmente trabalha com modelos utilizando ferramentas CAD.

## Objetivo

Criar uma presença digital profissional para apresentar:

- experiência;
- competência técnica;
- atuação profissional;
- trabalhos realizados;
- formas de contato.

Inicialmente, o produto será um site institucional/portfólio profissional, precedido por uma etapa de acolhimento e assessoria para alinhar história, gosto, posicionamento, conteúdo e identidade visual.

## Posicionamento

Apresentar Rute como profissional técnica de desenvolvimento de vestuário.

Evitar posicioná-la como costureira artesanal ou utilizar estética genérica de costura.

## Conceito

**Do molde à peça.**

O site deve comunicar a transformação de uma ideia ou modelo em uma peça preparada para produção.

## Direção Visual

Editorial contemporâneo combinando:

- moda;
- modelagem;
- desenvolvimento de produto;
- CAD;
- precisão técnica;
- experiência profissional.

### Evitar

- estética artesanal genérica;
- fundos florais;
- excesso de ícones de linha, agulha e tesoura;
- aparência de loja de roupas;
- aparência de e-commerce.

## Identidade Visual Inicial

Paleta:

- off-white;
- preto;
- grafite;
- bege;
- dourado suave.

A identidade poderá ser refinada ou a logo atual adaptada para integrar essa linguagem visual.

## Tecnologia

Projeto atualmente criado com:

- Next.js
- React
- TypeScript
- Tailwind CSS
- App Router

Não existe necessidade definida de:

- banco de dados;
- backend próprio;
- autenticação;
- API;
- cadastro de usuários.

Esses recursos só devem ser adicionados se surgir uma necessidade real e documentada.
